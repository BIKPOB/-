# Монитор пользовательской сети 0.9.5

Монитор включён автоматически. Он измеряет короткую HTTPS-загрузку с speed.cloudflare.com напрямую, когда VPN выключен. Сохраняются время, идентификатор сетевого сеанса, скорость полезной загрузки и время до HTTP-заголовков (включая DNS/TLS). Это оценка одного маршрута до тестового узла, не скорость тарифа, не ICMP ping и не тест потерь пакетов. Отдача и jitter в этой версии не измеряются.

Android: системный JobScheduler с периодом от 15 минут, с разрешением переноса со стороны ОС, включая Doze. Пока приложение открыто, результат обновляется каждые 30 секунд. При лимитном подключении тест не чаще двух часов, при безлимитном — 30 минут. При смене сети разрешён новый тест после пятиминутной паузы. Роуминг пропускается. Тест 1 МиБ для лимитной сети, 4 МиБ для безлимитной. Максимум 8/32 МиБ полезной загрузки в сутки, плюс DNS/TLS/HTTP. Неудачные попытки учитываются в лимите целиком. Все обнаруженные VPN приостанавливают прямые проверки. Начало собственного VPN отменяет текущий тест до запуска туннеля.

Windows: монитор живёт в процессе приложения, в том числе после сворачивания. Крестик сворачивает окно; команда «Выйти и отключить VPN» завершает работу. Автозапуск с Windows не устанавливается. Неизвестная стоимость сети обрабатывается как лимитная. При активном виртуальном адаптере прямой замер консервативно пропускается: это может быть другой VPN. Такой режим также может пропускать замер при Hyper-V. Сетевая сессия включает локальный хеш профиля подключения; имя сети не записывается в отчёт.

Свежий результат действует до двух часов и только для того же сетевого сеанса. Цель VPN — 60% от этого короткого прямого замера. Быстрый подбор продолжает поиск, если рабочий VPN не достигает цели, сохраняя кандидата для резервного подключения. Если база отсутствует или устарела, используется прежняя проверка. Глубокий подбор сравнивает измеренные варианты. Порог 60% — эвристика, не обещание скорости. Данные не публикуются на GitHub и не отправляются для обучения; HTTPS-тестовый сервис видит обычный запрос и исходный IP.

Проверки CI: свежесть и привязка базы к сети, сохранение данных, продолжение подбора после рабочего медленного VPN, весь набор Flutter-тестов, Android compilation/native checks и Windows TUN/installer checks. Поведение фонового планировщика на конкретном Samsung, пропускная способность LTE/Wi-Fi и влияние сторонних VPN требуют проверки на устройствах.
