### Существенные замечания Android

1. **Устаревшая нативная криптография.** В libopenvpn.so обнаружена строка
   `OpenSSL 1.1.1l 24 Aug 2021` и OpenVPN 2.5-icsopenvpn/v0.7.24.
   Общедоступная поддержка ветки OpenSSL 1.1.1 завершилась 2023-09-11.
   После 1.1.1l исправлялись уязвимости, например CVE-2022-0778 (ошибка обработки
   сертификатов, исправление 1.1.1n). Наличие/отсутствие backport-исправлений
   и эксплуатация конкретного бинарника не проверены. До замены/проверки движка
   APK не рекомендуется для повседневного использования.
2. **Экспортируемые служебные Activity:** VPNHelper, LaunchVPN,
   DisconnectVPNActivity. В манифесте они доступны другим приложениям без
   отдельного permission. Требуют анализа intent-обработчиков и ограничения
   экспорта там, где внешний вызов не нужен. Эксплуатация не проверялась.
3. Полный kill switch и гарантированная защита IPv6 не реализованы. Статус Connected
   с HTTPS-проверкой сам по себе не доказывает прохождение всего трафика через VPN.
4. Исходная APK-сборка не сохраняла pubspec.lock в артефакте. Точный полный граф её
   зависимостей нельзя подтвердить одним повторным разрешением версий. Проверка
   OSV для новой Windows-сборки не распространяется автоматически на старый APK.

## Исходники и файловые операции

- Импорт .ovpn ограничен размером, разрешённым набором директив и inline-сертификатами.
  Внешние файлы, плагины и исполняемые hooks не допускаются. Внешние команды
  Windows вызываются массивом аргументов, без shell-интерполяции профиля.
- Пароли и импортированные профили используют flutter_secure_storage.
  Публичный каталог сохраняется обычным JSON в каталоге поддержки приложения.
- Временные Windows-профили и management secret получают ACL текущего пользователя
  и SYSTEM, затем удаляются при штатном disconnect. После аварии процесса файлы
  могут остаться на диске; автоматическая очистка устаревших сессий не реализована.
- Management interface слушает loopback и использует случайный пароль.
- В новом Windows-коде добавлена проверка Authenticode-подписи издателя OpenVPN
  перед запуском runtime. Она не заменяет проверку DLL и версии установленного runtime.
- Windows UI запрашивает права администратора. Для production желательно вынести
  привилегированные операции в отдельную службу.
- Запросы приложения: каталог VPN Gate, HTTPS-проверка gstatic, выбранные VPN-серверы;
  в версии 0.3.0 также официальный swupdate.openvpn.net/org при установке Windows-движка. Это обзор исходников,
  не результат перехвата фактического сетевого трафика.
