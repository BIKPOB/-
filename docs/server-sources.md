# Источники серверов — проверка 19 сентября 2026

| Источник | Доступ | Реализованный способ | Ограничения |
|---|---|---|---|
| VPN Gate | Публичный CSV с OpenVPN-конфигурациями | Автоматическая загрузка HTTPS, страны, кэш | Волонтёрские узлы; нет гарантии региона или доступности |
| VPNBook | Выбор сервера/протокола на сайте, общий логин и сменяемый пароль | Открыть официальный сайт → скачать .ovpn → импорт → ввести текущие реквизиты | Пароль не зашит в приложение; документированный публичный API на проверенной странице не найден |
| VPN Jantit | Выдача временных аккаунтов и профилей | Официальная выдача аккаунта → импорт .ovpn → ввод реквизитов | Заявлен срок до 7 дней; аккаунт придётся обновлять |
| Собственный OpenVPN | Ваш .ovpn | Тот же локальный импорт | Нужны ваши серверы и доступ |

VPNBook на проверенной странице перечисляет OpenVPN в США, Канаде, Великобритании,
Германии и Франции. VPN Jantit заявляет 62 страны и 90 городов; это заявление
провайдера, а не результат проверки подключений. VPN Gate отдаёт географию динамически.
Регион в UI — метаданные провайдера, не независимое измерение местоположения exit IP.

FreeOpenVPN.org также проверен: он перенаправил на IPSpeed.info, где доступного
машиночитаемого каталога OpenVPN на открытой странице не обнаружено. Он не добавлен
как работающий источник. Случайные репозитории с неизвестными .ovpn/ключами
не используются: происхождение и актуальность таких профилей не подтверждены.

## Официальные источники

- VPN Gate: https://www.vpngate.net/en/
- CSV: https://www.vpngate.net/api/iphone/
- Политика журналов: https://www.vpngate.net/en/about_abuse.aspx
- VPNBook: https://www.vpnbook.com/freevpn/openvpn
- VPN Jantit: https://www.vpnjantit.com/free-openvpn
- Проверенная переадресация: https://www.freeopenvpn.org/ → https://ipspeed.info/

VPN Gate сообщает о хранении connection logs не менее трёх месяцев и packet-header
logs на реле не менее двух недель. Публичные реле нельзя представлять как no-log
инфраструктуру. Для конфиденциальных рабочих данных используйте доверенные серверы.

## Как добавить новый источник

Сначала подтвердить право подключения и официальный формат выдачи профилей.
Если провайдер публикует документированный HTTPS API — добавить отдельный repository
с ограничением размера ответа, cache TTL и тестовыми fixtures. Если нужна выдача
аккаунта/капча — использовать официальный пользовательский поток и импорт.
Не переносить токены или приватные профили пользователя в публичный каталог.

Импорт поддерживает ограниченное подмножество .ovpn: один remote, TUN, inline CA,
опциональные inline cert/key/tls-auth/tls-crypt. Внешние файлы, скрипты, плагины,
несколько remote, TAP и нестандартные директивы отклоняются. Поэтому совместимость
каждого профиля VPNBook/Jantit проверяется при импорте, а не заявляется для всех профилей.
