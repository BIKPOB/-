# Подбор и проверка Xray 0.9.3

- Версия основана на 0.9.2 и сохраняет её ограничения числа кандидатов, бюджеты времени, приоритет истории и возврат к рабочему медленному профилю.
- На Android VLESS и Shadowsocks проверяются HTTPS-запросом и загрузкой 256 КиБ непосредственно через локальный SOCKS Xray. Сокет до SOCKS остаётся локальным, целевое имя передаётся Xray, а TLS-сертификат проверяется по исходному имени.
- Повторная проверка Xray через Android VPN Network удалена: процесс приложения может быть исключён из TUN для предотвращения петли маршрутизации, что раньше давало ложный таймаут после уже успешного HTTPS через SOCKS.
- Быстрый подбор сразу оставляет включённым первый полностью измеренный рабочий VPN. Скорость ниже 128 КиБ/с показывается как ниже цели, но соединение больше не отключается ради продолжения перебора.
- Глубокий подбор по-прежнему может сравнить два рабочих варианта. Пропускная способность публичного сервера от этого не увеличивается.
- WireGuard подтверждается только после callback нативного движка и отдельной HTTPS-проверки. Профили без обмена продолжают отклоняться по таймауту.

CI проверяет код, конфигурацию, Android native tests, Windows TUN и установщик. Доступность публичных серверов на конкретном Wi-Fi/LTE подтверждается только тестом на устройстве.
