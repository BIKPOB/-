# Quiet VPN 1.0.15

## Подбор при частичной доступности и массовых сбоях
- Режим восстановления включается, когда российский контрольный адрес доступен, а оба внешних не подтверждены; в глубоком подборе он также включается после неудачного предыдущего раунда с восемью и более проверенными профилями.
- Отдельная история подтверждённых подключений в режиме восстановления учитывает текущую сеть и оператора, если он доступен системе. Записи живут до 7 дней; сохраняются только хеши идентификаторов, без ключей и адресов профиля.
- Очередь распределяет попытки между разными адресами, IP-подсетями и транспортами. Списки серверов не сокращаются; неизвестный пинг не подменяется оценкой.
- Предварительная проверка в этом режиме проверяет HTTPS без скачивания тестовых мегабайтов: до 6 кандидатов одновременно на лимитной сети, до 12 на безлимитной. Два контрольных HTTPS-адреса проверяются параллельно; достаточно первого настоящего успешного ответа. После успешной группы начинается проверка системного VPN.
- IP-адреса кандидатов не зависят от системного DNS. Доменные имена, SNI и проверка сертификатов сохраняются; фиктивные DNS-ответы не используются.
- Быстрый подбор сохраняет общий лимит 15 секунд; предварительной группе выделяется до 5 секунд. В глубоком восстановлении скрининг ограничен 18 секундами на раунд, попытка туннеля — 15 секундами плюс безопасное завершение остановки.
- Первый подтверждённый системный VPN сохраняется даже без замера скорости или при скорости ниже цели. Он не отключается ради очередного сравнения. Неизмеренная скорость остаётся неизвестной.
- Массовые неудачи в режиме восстановления не снижают рейтинг источников; успешные подключения продолжают обучать подбор.

## Windows
- Быстрая проверка теперь подтверждает DNS и HTTPS через TUN без обязательного теста загрузки.
- Два контрольных адреса проверяются конкурентно. Ошибка первого не отменяет успешный ответ второго; оба отказа не превращаются в фиктивное подключение.
- Проверки остаются привязаны к VPN-интерфейсу. Доступ через DoH при неисправном обычном DNS не объявляется исправным системным VPN.

## Проверка
Моделируемые сценарии: отказ одного/обоих HTTPS-контролей, сбой DNS для IP-профиля, отмена зависших запросов, отсутствие ложных положительных результатов, история разных операторов, сохранение первого HTTPS-туннеля без скорости и без переподключения. Выполняются стандартные сборочные и нативные проверки Android/Windows.

Ограничение: этот алгоритм эффективнее ищет доступный вход среди имеющихся профилей. Если оператор не пропускает ни один из их адресов, нужен реально доступный сервер входа; новый алгоритм сам по себе такой маршрут не создаёт. Работа при реальных ограничениях MegaFon/T2 в этом релизе не подтверждена полевым тестом.
