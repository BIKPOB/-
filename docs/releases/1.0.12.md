# Quiet VPN 1.0.12 — исправления по результатам аудита 1.0.11

- Контрольные запросы `/generate_204` требуют именно HTTP 204. Ответ 200 с посторонней страницей и перенаправления больше не подтверждают доступность. Проверка скорости требует HTTP 200 и полного ожидаемого объёма данных.
- Успех на другой сети не отменяет десятиминутную паузу повторного предпочтения сервера после неподтверждённой попытки в текущей сети. Подтверждённое повторное подключение в текущей сети снимает паузу.
- Повреждённые строки журнала обучения пропускаются по отдельности. Некорректные значения скорости и задержки не вызывают ошибку ранжирования и не стирают корректные веса модели.
- Оценки источников фиксируются на время сортировки. Затухание истории больше не меняет оценки внутри одного сравнения очереди; повторные вычисления одного профиля исключены.
- Опубликован отдельный патч-ноут 1.0.11; описание нового релиза берётся из файла своей версии.

Добавлены регрессионные проверки HTTP-ответов через локальный сервер, истории двух сетей и восстановления повреждённого журнала. Локальный тест HTTP проверяет обработку ответа; он не имитирует успешное соединение с публичным VPN.

Задержка остаётся реальным временем HTTPS-проверки, а не ICMP-пингом. Не обещаем устранения всех ошибок Xray или доступности любого публичного сервера. Проверка пользовательской сети и реальных устройств необходима отдельно. Интерфейс и дизайн не изменены.
