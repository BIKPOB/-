# Quiet VPN 1.0.17

## Входные профили для мобильных ограничений
- Подключена отдельная опубликованная igareck подборка Vless-Reality-White-Lists-Rus-Mobile. Совместимые VLESS-профили доступны в списке и автоматическом подборе.
- В приложение включена копия подборки от 14.11.2026: для первого поиска не требуется доступ к GitHub. Исходный снимок и лицензия сохранены отдельно.
- Для этой публичной подборки добавлено указанное автором зеркало через Яндекс/Bitbucket наряду с GitHub и githack. Принимается только ответ с совместимыми профилями; HTML-страница или ошибка не заменяет сохранённую базу. Частные ссылки подписок через зеркало не передаются.
- Небольшая подборка обновляется в фоне при работе автоматического анализатора, не чаще одного раза в 30 минут. Быстрый поиск не ждёт загрузки. При отказе источников используются проверенные по формату снимки и встроенная копия.
- Экран каталога, быстрый поиск и резерв используют общий каталог в памяти. Новое обновление не теряется между отдельными экземплярами загрузчика.
- Старые источники и профили сохранены. Неподдерживаемые протоколы не преобразуются в фиктивные VLESS-профили. Название upstream-подборки не считается проверкой работоспособности: пинг и подключение подтверждаются на устройстве.

## Диагностика сети
В отчёте контрольных HTTPS-проверок отдельно отображаются явная ошибка разрешения имени, ошибка TLS/сертификата, неожиданный HTTP-ответ, таймаут и ошибка соединения. Причина фильтрации не угадывается по одному SocketException.

## Проверки
Тесты проверяют совместимость встроенных профилей, сохранение прежней базы при отказе загрузки, неблокирующее обновление, объединение каталога и типы ошибок контрольных запросов.

Проверка при действующих ограничениях MegaFon/T2 пока не выполнена. Это добавление реальных опубликованных входных конфигураций, а не гарантия доступности любого адреса и не собственная серверная инфраструктура.
