# Quiet VPN 1.0.18

- Android определяет оператора активной передачи данных уже при запуске, независимо от включения расширенного анализа. Поддерживаются МТС, МегаФон, T2, Билайн и другие сети, сообщаемые Android.
- SIM для звонков не подменяет SIM для интернета. На Android 11+ используется активная подписка передачи данных; при отсутствии сведений оператор остаётся неопределённым. На Android 8–10 доступна системная подписка данных по умолчанию.
- В информации о сети отображается оператор; при отличающемся операторе SIM он показывается отдельно. Wi-Fi не получает название оператора установленной SIM.
- Оценка источников профилей разделена по коду текущей мобильной сети, оператору SIM и роумингу. Старые общие оценки мобильных источников не объявляются опытом конкретного оператора. Подтверждённые результаты сохраняются локально; общая телеметрия тестировщиков не собирается.
- Смена SIM или зарегистрированной сети изменяет идентификатор соединения: предыдущие замеры, резерв и результаты незавершённого поиска больше не считаются актуальными. Прямой замер скорости отбрасывается, если SIM сменилась во время загрузки.
- Для определения оператора не добавлены запросы к внешним IP-сервисам, новые движки или постоянное сканирование. Дополнительное разрешение телефона по-прежнему используется только для расширенных сведений о радио/сигнале.

Проверки: разделение обучения между четырьмя операторами, неизвестная сеть, роуминг, разные SIM-провайдеры, выбор активной SIM вместо основной, получение сведений без расширенного режима и разрешения READ_PHONE_STATE.

Это улучшение определения сети и порядка подбора, не гарантия подключения при белых списках. Доступность при ограничениях всех четырёх операторов требует полевых результатов. Автоматическое определение оператора телефона за Wi-Fi-раздачей на Windows не заявляется.

API: https://developer.android.com/reference/android/telephony/SubscriptionManager#getActiveDataSubscriptionId()
https://developer.android.com/reference/android/telephony/TelephonyManager#getNetworkOperator()
